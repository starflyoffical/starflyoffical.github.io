01 — 04 · SIGN & INSTALL

用 Sideloadly 安裝 IPA

以下步驟依 Windows 版 Sideloadly 編排；不同版本的按鈕位置可能略有差異。

01
DOWNLOAD · 下載工具與 IPA

下載 Sideloadly 與選擇版本

從 Sideloadly 官方網站下載並安裝 Windows 版工具。免費版與 Pro IPA 都可由官網下載。Pro 需另購啟用授權碼，請由官網上的官方 LINE 洽購。

下載免費版 IPA ↓ 下載 Pro IPA ↓
IPA 尚未簽署，不能直接在 iPhone 開啟；請依後續步驟用 Sideloadly 簽署。Pro 授權碼須另行購買，請前往官網授權碼購買區聯絡官方 LINE。
02
CONNECT · 連接 iPhone

解鎖手機，再接上 USB

保持 iPhone 解鎖並連接電腦。如果手機出現「信任此電腦」，確認是自己的電腦後點「信任」，再輸入 iPhone 密碼。回到 Sideloadly，確認上方裝置欄選到你的 iPhone。

裝置清單空白時：換一條支援資料傳輸的線、重新插拔，並確認 iPhone 已解鎖。
03
SIGN · 使用自己的 Apple ID 簽署

放入所選 IPA，按 Start 開始

  1. 把剛才下載的免費版或 Pro 版 IPA 拖到 Sideloadly 視窗，或按左側 IPA 圖示選取。
  2. 在 Apple ID 欄位輸入你自己的帳號，再確認裝置欄是正確的 iPhone。
  3. 按 Start，依畫面提示完成 Apple 登入與雙重認證。
  4. 等到狀態顯示 Done，再從 iPhone 主畫面尋找 StarFly。
Apple 驗證碼只在你自己的 Sideloadly 登入流程中輸入。官方 LINE 客服不需要你的 Apple ID 密碼或驗證碼。
↻免費 Apple ID 的期限

Sideloadly 官方說明：免費帳號簽署的 App 通常可使用 7 天。可在 Sideloadly 設定自動重新簽署；自動刷新仍需要電腦能透過 USB 或已設定的 Wi‑Fi 偵測到裝置。若 App 失效，使用相同 Apple ID 重新安裝最新版。

04
DEVELOPER MODE · 開啟開發者模式

照文字步驟完成啟用與配對

  1. 先在 StarFly「裝置設定」點「配對此 iPhone」開始配對，並依 App 提示前往設定。
  2. 打開「設定 → 隱私權與安全性 → 開發者模式」，開啟開關並依提示重新啟動 iPhone。
  3. 重新開機後，在確認畫面點「啟用」，再輸入 iPhone 解鎖密碼。
  4. 回到「設定 → 隱私權與安全性 → 開發者模式」，在「其他裝置」下點「Pair with StarFly」（部分介面會顯示「與 StarFly 配對」）。
  5. 依 iPhone 畫面輸入 StarFly 顯示的六位數配對碼並確認；如出現本機網路權限提示，請允許 StarFly 存取。
如果一開始看不到「開發者模式」，先讓 StarFly 的配對流程保持啟動，再回設定查看。配對期間不要關閉 StarFly，並保持 Developer Mode 開啟。
開發者模式會降低部分裝置安全保護；只在安裝並使用你信任的 App 時開啟。
05 · TRUST ON IPHONE

第一次開啟前，信任簽署者

若跳出「未受信任的開發者」，先取消提示，再到設定中信任剛才用來簽署的開發者。

1
先點「取消」

不要重複點開 App；返回 iPhone 主畫面。

2
打開 VPN 與裝置管理

「設定 → 一般 → VPN 與裝置管理」。

3
選取 Developer App

在「開發者 App」區域，點選這次 Sideloadly 簽署所使用的開發者帳號。

4
只信任你剛才使用的帳號

按「信任……」並在確認視窗再次允許。完成後回主畫面開啟 StarFly。

只對你認得、而且與自己剛才使用的 Apple ID 相符的簽署者按「信任」。不要照抄別人的信任畫面上的帳號或團隊代碼。
06 · ACTIVATE STARFLY

完成首次設定

免費版可直接進入 App。StarFly Pro 首次開啟時，請輸入 Pro 授權碼並啟用此設備；授權碼與 Apple ID 不同，也不會由 Sideloadly 產生。

配對紀錄儲存在此 iPhone 的鑰匙圈中；StarFly 不會上傳配對檔。
07 · LOCAL CONNECTION

安裝並連接 LocalDevVPN

StarFly 透過 LocalDevVPN 在你的 iPhone 上建立本機連線通道；它不是用來替代一般上網 VPN 的服務。

⌁
APP STORE
LocalDevVPN

由 App Store 安裝，確認開發者與 App 名稱正確。

在 App Store 查看 LocalDevVPN ↗ App Store 官方連結 · 免費下載（以商店頁面為準）
1
安裝後開啟 LocalDevVPN

第一次連線時，iOS 可能詢問是否允許新增 VPN 設定；確認這是你剛從 App Store 安裝的 LocalDevVPN，再依系統提示操作。

2
啟用本機通道

回到 LocalDevVPN，啟動它的連線並確認狀態為已連線。開始 StarFly 位置工作階段期間，保持通道啟用。

3
回到 StarFly 完成配對或重試

如果 StarFly 顯示「仍在連線」，先確認 LocalDevVPN 已連線，再點「再試一次」。Wi‑Fi 使用者不要誤選行動數據流程。

若同時使用其他 VPN、防火牆或公司管理設定，可能影響本機連線。只在你了解網路影響且允許的情況下暫停其他 VPN 做比較測試。
OPTIONAL · MOBILE DATA

行動數據流程捷徑
Wi‑Fi 使用者可略過

這個 iCloud 捷徑叫「StarFly 網路流程」。它配合 StarFly 的行動數據連線引導，在需要時切換行動數據關閉／重新開啟，接著返回 App 繼續連線。

取得 StarFly 網路流程捷徑 ↗
「設定行動數據」是否可用，可能受 iOS、電信商或裝置管理政策影響；若動作無法執行，請依 StarFly 畫面手動完成步驟。
01
在 iPhone 開啟 iCloud 捷徑連結

按「取得捷徑／加入捷徑」，並在「捷徑」App 確認已加入，名稱保持「StarFly 網路流程」。

02
讓 StarFly 使用這個名稱

回 StarFly，開啟「控制中心 → 捷徑流程」，輸入完全相同的名稱，再開啟「需要時自動執行捷徑」。

03
只在實際使用 4G／5G 時跟著引導操作

StarFly 需要暫時關閉行動數據時，捷徑會處理關閉；連線準備完成後，再執行開啟行動數據的捷徑。iOS 會返回 StarFly 繼續偵測。

安全提醒此捷徑會切換行動數據狀態；請先查看捷徑動作內容，只加入你信任的捷徑。若你只用 Wi‑Fi，無須安裝或啟用它。
TROUBLESHOOTING

遇到問題？先看這裡

按下方問題展開排查方法；求助時請遮住 Apple ID、驗證碼與授權序號。

Sideloadly 看不到 iPhone，怎麼辦？

解鎖 iPhone、重新插拔資料線，並在手機端允許「信任此電腦」。確認電腦已安裝 Sideloadly 官方要求的 Apple 裝置元件；重新啟動 Sideloadly 和電腦後再試。不要下載不明的驅動程式。

安裝成功，但跳出「未受信任的開發者」？

先取消提示，再到「設定 → 一般 → VPN 與裝置管理 → 開發者 App」，選取你剛才在 Sideloadly 使用的開發者並按「信任」。信任前先確認 IPA 來源和開發者身分。

StarFly 七天後打不開或顯示無法驗證？

免費 Apple ID 的簽署效期通常為 7 天，且同時可側載的 App 數量有限。用同一個 Apple ID 重新側載最新版 IPA，或事先在 Sideloadly 啟用自動刷新並確保電腦能偵測 iPhone。更新時不要先刪除舊 App，否則可能清掉本機設定並需要重新配對。

Pro 要求授權碼，Apple ID 可以代替嗎？

不可以。Apple ID 只供 Sideloadly 簽署；Pro 授權碼是另一項裝置授權。免費版不需要購買 Pro 授權。請透過官方 LINE @689whbkl 洽詢 Pro 方案。不要在公開頁面張貼完整授權碼。

LocalDevVPN 顯示已連線，StarFly 還是找不到 iPhone？

確認配對的是目前這部實體 iPhone，允許 StarFly 使用本機網路，並確認 LocalDevVPN 通道仍開啟。Wi‑Fi 請使用 Wi‑Fi 連線流程；只有真的在使用 4G／5G 時才選行動數據流程。前往 StarFly「設定 → 連線診斷」可查看狀態。

更新版本會不會清除我的資料？

使用相同 Apple ID 安裝相同 StarFly App 的新版 IPA，通常可覆蓋更新並保留 App 資料。不要先刪除 App；若要換簽署帳號或遇到簽章錯誤，先洽官方 LINE 確認再處理。

NEED A HAND?

卡在某一步？官方 LINE 可以協助你。

傳送「卡住的步驟編號＋錯誤畫面」即可；請先遮住 Apple ID、驗證碼、授權序號與配對碼。
