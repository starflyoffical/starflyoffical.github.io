StarFly 官網與安裝教學

本資料夾可直接放到支援靜態網站的主機。首頁不依賴外部字型、CDN、分析套件或遠端圖片；所有版面、插圖、動畫與互動由本機 HTML、CSS、JavaScript 和 assets 提供。

頁面
- index.html：StarFly 官網首頁、功能介紹、免費版／Pro 比較、下載專區、常見問題與聯絡入口
- install.html：保留的完整安裝指南，含免費版和 Pro IPA 下載按鈕
- terms.html：服務條款草稿
- privacy.html：隱私權政策草稿

資源
- site.css、site.js：官網版面、響應式導覽與動畫
- typography.css：官網、安裝指南、條款與隱私頁共用字體規則
- legal.css：條款與隱私權頁版面
- styles.css、script.js：原安裝指南版面與 LINE ID 複製功能
- assets：StarFly 圖示與 11 張已遮蔽個資的安裝教學參考圖
- downloads/StarFly-unsigned.ipa：免費版，未簽署
- downloads/StarFly-Pro-unsigned.ipa：Pro 版，未簽署

免費版與 Pro IPA 已由桌面原檔複製到 downloads/，皆尚未簽署，需由使用者透過 Sideloadly 等工具使用自己的 Apple ID 簽署。Pro 安裝檔可直接下載；授權碼透過官網的官方 LINE 洽購，確認付款後由管理端發放。本網站為靜態網站，不會連接購買 API。

- 自有後端與網站主機的實際供應者／處理地區、各類資料保存期間
- 確認正式 IPA 版本、Build 與網站所列功能一致
