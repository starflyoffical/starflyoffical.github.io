StarFly 安裝教學網頁

開啟方式：雙擊 index.html，使用 Chrome、Edge 或 Safari 檢視。

資料夾內容：
- index.html：完整繁體中文教學頁
- styles.css、script.js：版面與 LINE ID 複製按鈕
- assets：StarFly 圖示及 11 張教學參考圖；網站使用的是本機遮蔽後副本
- downloads/StarFly-unsigned.ipa：頁面提供下載的未簽署 IPA

網站內容已包含 Sideloadly、Apple Developer Mode 文字步驟、Apple 信任說明、LocalDevVPN App Store 及你提供的 StarFly 網路流程捷徑連結。Sideloadly 請由官方網站下載；IPA 尚未簽署，需先用 Sideloadly 簽署才能安裝。若要放到網路供人瀏覽，請將整個資料夾上傳至靜態網站主機，並保留 assets 與 downloads 子資料夾。
